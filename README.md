\# Optimasi Biaya Sewa Cloud Server



\## Mata Kuliah

Pemodelan dan Simulasi



\## Deskripsi

Program Python untuk menentukan kombinasi durasi sewa

Server Standar dan Server Performa Tinggi dengan biaya

minimum berdasarkan kebutuhan pemrosesan data dan

akses basis data.



\## Data Kasus

\- Server Standar: 20 instruksi dan 10 akses basis data per jam.

\- Biaya Server Standar: Rp8.000 per jam.

\- Server Performa Tinggi: 10 instruksi dan 30 akses basis data per jam.

\- Biaya Server Performa Tinggi: Rp12.000 per jam.

\- Kebutuhan minimum: 100 instruksi dan 90 akses basis data.



\## Hasil

\- Durasi Server Standar: 4,2 jam.

\- Durasi Server Performa Tinggi: 1,6 jam.

\- Biaya minimum: Rp52.800.



\## Cara Menjalankan

1\. Pastikan Python telah terinstal.

2\. Buka terminal pada folder proyek.

3\. Jalankan `python optimasi\_server.py`.
